# Stretch-Rx

A simple web app for exploring stretches and mobility exercises.  
Built with **HTML, CSS, and vanilla JavaScript**.

## Features
- 📂 Loads structured data from `stretches.json`
- 🃏 Renders stretch cards dynamically with images, steps, and duration
- 🔍 Search by name or muscle group
- 🎯 Filter by upper body, lower body, or full body
- ⭐ Save favorite stretches (stored with `localStorage`)

## Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- JSON (data source)
